# Analisis Faktor-Faktor yang Memengaruhi Indeks Massa Tubuh (BMI) Remaja di Indonesia

**Mata Kuliah:** Probabilitas dan Statistika  
**Program Studi:** Teknik Informatika, Politeknik Caltex Riau  
**Kelompok 9, Kelas 3TI B**

## Deskripsi Proyek

Proyek ini menganalisis karakteristik Indeks Massa Tubuh (BMI) remaja Indonesia secara **deskriptif** menggunakan Python (Pandas dan Matplotlib). Dataset yang digunakan berisi 351 observasi dengan variabel utama: Usia, Berat Badan (kg), dan BMI. Fokus analisis adalah menggambarkan distribusi dan karakteristik data tanpa pengujian inferensial.

## Rumusan Masalah

1. Bagaimana karakteristik dan distribusi BMI, berat badan, dan usia pada remaja?
2. Bagaimana gambaran distribusi BMI remaja jika dilihat berdasarkan kelompok usia?
3. Bagaimana gambaran perbandingan BMI remaja laki-laki dan perempuan secara deskriptif?
