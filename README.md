# Analisis Faktor-Faktor yang Memengaruhi Indeks Massa Tubuh (BMI) Remaja di Indonesia

**Mata Kuliah:** Probabilitas dan Statistika  
**Program Studi:** Teknik Informatika, Politeknik Caltex Riau  

## Deskripsi Proyek
Proyek ini merupakan tugas analisis data untuk mengeksplorasi karakteristik Indeks Massa Tubuh (BMI) remaja menggunakan bahasa pemrograman Python (berbasis Pandas dan SciPy). Dataset yang digunakan memiliki 351 baris observasi unik yang berfokus pada variabel utama: **Usia**, **Berat Badan (kg)**, dan **BMI**. 

## Rumusan Masalah
1. Bagaimana karakteristik dan distribusi BMI, berat badan, dan usia pada remaja?
2. Apakah terdapat hubungan antara usia dengan BMI?
3. Apakah terdapat perbedaan rata-rata BMI antara remaja laki-laki dan perempuan?

## Teknologi yang Digunakan
- Python 3
- Pandas (Manipulasi & Visualisasi Data Deskriptif)
- SciPy (Pengujian Hipotesis Korelasi & Komparasi)
- Google Colaboratory
